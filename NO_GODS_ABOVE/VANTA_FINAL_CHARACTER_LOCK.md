# VANTA FINAL — Character Lock

Use **Vanta Reign** as the canonical rival / enemy / future Player 2 character.

## Visual Design Lock

- male dark cyber samurai / cyber ninja
- black armor
- crimson / dark red energy forearm blades
- red visor
- compact readable fighting-game silhouette
- slightly heavier and more aggressive than Kairo
- no chains
- no cape
- no long cloth trails

## Runtime Rules

- use clean sheets only as runtime assets
- all sheets use 6 columns x 5 rows
- slice uniformly
- use bottom-center anchoring
- keep grounded feet aligned to one shared ground baseline
- body stays above the baseline
- dash / projectile / special travel should be handled in code
- do not treat sprite-internal pose shifts as world movement

## Relationship to Kairo

Kairo = cyan cyber blade striker.
Vanta = crimson rival.

Vanta should usually spawn on the right side of the screen and face Kairo.
If Vanta is on the right, mirror him horizontally in code.
