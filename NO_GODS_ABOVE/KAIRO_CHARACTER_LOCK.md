# KAIRO NULL — CHARACTER LOCK

This patch replaces the previous playable character with **Kairo Null**.

## Canonical Character

Kairo Null is the only playable character for this patch.

Visual lock:
- Male cyber ninja fighter
- White / silver spiky hair
- Black tactical cyber armor
- Cyan glowing armor accents
- Cyan dual forearm energy blades
- Masked lower face / visor-like face treatment
- Compact, readable fighting-game silhouette
- No chain weapons
- No whip weapons
- No long cape that causes frame overlap
- No letters, labels, headers, or UI baked into sprite sheets

## Important

Do not use old Veyra sheets, Seraphine sheets, chain-whip sheets, or early chibi test characters as the active playable character.

Use only these active production sheets:

```txt
assets/sprites/kairo/kairo_basic_movement.png
assets/sprites/kairo/kairo_core_attacks.png
assets/sprites/kairo/kairo_back_low_attacks.png
assets/sprites/kairo/kairo_air_specials.png
assets/sprites/kairo/kairo_states_ultimate.png
```

The files in `assets/unused_reference/` are not gameplay assets. They are only style references if needed.
