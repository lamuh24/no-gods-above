# KAIRO FINAL — Character Lock

Use Kairo as the canonical Player 1 character.

## Visual Design Lock
- male cyber ninja
- white / silver spiky hair
- black tactical armor
- cyan energy forearm blades
- black face mask
- compact readable fighting-game silhouette
- no chains
- no cape

## Runtime Rules
- use clean sheets only as runtime assets
- all sheets use 6 columns x 5 rows
- slice uniformly
- keep bottom-center anchoring
- keep feet aligned to a shared ground baseline
- keep movement travel in code, not in sprite offsets
