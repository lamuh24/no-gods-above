# Lamuh Legacy V2 candidate source

This is a non-deployable first-playable candidate. The protected V1 images remain byte-identical in their original locations. The retired `characters/lamuh` motion fixture is historical test data and is not a source for this rebuild.

Authoritative candidate records:

- `source-lock.v1.json` — immutable V1 source, atlas, VFX, and legacy `game.js` hashes.
- `source-audit.v1.json` — source-of-truth motion/gameplay inventory with historical and current-Legacy columns.
- `timing-candidates.v1.json` — independent A/B/C exposure and phase candidates.
- `throws.standard-humanoid.v1.json` — deterministic standard-height victim contract.
- `first-playable.bundle.json` — current milestone coverage and known debt.
- `FIRST_PLAYABLE_REQUIREMENTS_AUDIT.md` — evidence map for every first-playable slot and the current human stop gate.
- `style-checkpoint.v1.json` — hash-bound visual-direction checkpoint.
- `records/style-checkpoint-v1.approval.json` — human approval of the style direction with targeted repair; it does not approve runtime art or production.
- `COMBAT_IDENTITY.md` — human-review identity proposal.

No record in this folder is a production approval.
