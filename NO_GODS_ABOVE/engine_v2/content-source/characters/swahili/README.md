# Swahili Content-Source Reservation

Swahili is authorized as a Forge production candidate, not as a runtime/public-roster integration.

The authored Forge entry lives at `tools/nga-forge/production/characters/swahili/`. This directory intentionally does not contain `character.bundle.json` yet: the production schema requires real individual source frames, deterministic exposures, anchors, and valid Animation Packages. The supplied turnaround/detail sheet is approved only as a design reference and cannot satisfy those requirements.

Publish the bundle here only after the required idle and standing-heavy/recovery frames, weapon action, and combat timing are human-approved. Until then there is nothing valid to compile.
