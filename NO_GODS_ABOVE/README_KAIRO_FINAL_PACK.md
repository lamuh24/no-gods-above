# KAIRO FINAL PACK

This pack contains the final clean Kairo sprite sheets for `NO GODS ABOVE`.

## Included sheets
- Sheet 1 — Basic Movement
- Sheet 2 — Defense / Recovery
- Sheet 3 — Core Attacks A
- Sheet 4 — Core Attacks B
- Sheet 5 — Low / Air
- Sheet 6 — Specials / Ultimate
- Sheet 7 — End States / Extras

## Grid Standard
- 6 columns x 5 rows per sheet
- 6 frames per row
- 5 animation rows per sheet
- solid #ff00ff magenta background
- no labels / no text / no debug lines

## Import Notes
Use uniform grid slicing for every sheet.
Do not use any old Kairo V1 / Kairo V2 mixed assets in place of these files.
