# KAIRO NULL Character Patch

This ZIP is a clean character replacement/add-on for **NO GODS ABOVE**.

It adds **Kairo Null**, a male cyber ninja fighter with white/silver hair, black tactical armor, and cyan forearm energy blades.

## What To Do In Codex

Upload this ZIP into the existing project and paste `KAIRO_CODEX_IMPORT_MESSAGE.txt`.

Then tell Codex:

```txt
Replace the active playable character with Kairo Null. Use docs/kairo_animation_map.md and docs/kairo_moveset.md. Do not use previous Veyra, Seraphine, chain-whip, or chibi assets as the active player.
```
