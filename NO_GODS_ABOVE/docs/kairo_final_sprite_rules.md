# KAIRO FINAL — Sprite Rules

- clean sheets only for runtime
- every sheet uses a uniform 6 x 5 grid
- every row has exactly 6 frames
- every sheet has exactly 5 rows
- use bottom-center anchoring
- feet on grounded rows should align to a shared invisible ground baseline
- body should stay above the baseline
- keep same character scale and camera distance across all sheets when possible
- keep no text / no labels / no grid lines in runtime assets
- if hitbox or VFX issues occur, prefer code-side handling instead of shifting sprite roots
