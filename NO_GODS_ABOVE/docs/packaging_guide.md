# NO GODS ABOVE — Packaging Guide

## Before Giving to Codex

Check that handoff.md and README.md are top-level, docs are inside docs/, all assets are in assets/, and audio folders exist even if empty.

## Codex First Message

Use CODEX_START_HERE_MESSAGE.txt first, then tell Codex to use docs/codex_build_prompt.md as the build instruction.

## Rule

Do not regenerate assets forever. Build the playable prototype first.
