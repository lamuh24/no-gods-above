# Kairo V2 Patch

This patch contains a cleaner Kairo replacement set for the player character.

Included files:
- assets/sprites/kairo_v2/kairo_basic_movement.png
- assets/sprites/kairo_v2/kairo_core_attacks.png
- assets/sprites/kairo_v2/kairo_back_low_attacks.png
- assets/sprites/kairo_v2/kairo_air_specials.png
- assets/sprites/kairo_v2/kairo_states_ultimate.png

Goal:
Replace the previous active player character with Kairo V2 and reduce sliding / overlap issues by using better row mapping plus stricter sprite handling rules.
