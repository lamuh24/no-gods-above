# Asset and Animation Pipeline

For every production fighter preserve locked references, original generated mesh, production `.blend`, runtime GLB, source/runtime textures, rig version, animation sources, export manifest, provenance, and validation reports.

Tripo is optional and replaceable. Generate candidates and separate complex accessories when animation requires it. Only approved candidates move to production.

Build reusable NGA bases/rig families, shared reactions, toon materials, weapon sockets, grab/victim anchors, camera targets, and VFX anchors. Do not force every anatomy onto one rig.

Combat translation is engine-owned. Export clips in place unless an explicit validated motion curve exists.

Throws and command grabs use synchronized attacker/victim clips, alignment anchors, impact/release markers, and body-size compatibility tests.

Production order: engine-proof movement/reactions/one throw/one ultimate; normals; specials; reactions/recovery; throws/command grabs; presentation; cinematic polish.

The “3D sprite” look comes from stylized models, toon shading, outlines, simplified textures, held key poses, stepped visual animation while simulation stays at 60 Hz, and optional pre-rendered Blender shots for selected ultimates.

Runtime export checks include scale/axes, named clips, no accidental root motion, material/texture/bone budgets, skin weights, bounding volumes, LODs, and separate web/Steam quality profiles.
