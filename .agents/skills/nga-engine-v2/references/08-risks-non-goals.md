# Risks and Non-Goals

Primary risks:
- Scope explosion: control with vertical slices and frozen non-benchmark roster work.
- Asset-provider dependency: export standard formats, archive source, preserve provenance, and keep provider adapters replaceable.
- Agent inconsistency: use small branches, explicit invariants, tests, captures, and approval gates.
- Binary conflicts: use single-writer ownership, LFS/object storage, manifests, and checksums.
- Web performance: enforce quality profiles, compression, LODs, and measured budgets.
- Rollback debt: maintain deterministic serializable simulation from Phase 1.
- Camera readability/motion sickness: safe volumes, restoration tests, reduced-motion modes.
- Grab incompatibility across body types: rig families, size classes, anchors, and automated previews.
- Real-time/pre-render mismatch: share models, materials, lighting, color pipeline, and approval comparisons.

Initial V2 non-goals:
- Public arbitrary character imports.
- M.U.G.E.N compatibility.
- Full legacy roster immediately.
- Tag-team mode.
- Stage destruction/transitions.
- Multiple ultimates per fighter.
- Universal parry or environmental weapons.
- Full matchmaking before deterministic local simulation.
- Replacing every external library with custom low-level code.
- Building a custom 3D modeling application.
