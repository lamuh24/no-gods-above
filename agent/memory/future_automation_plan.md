# Future Automation Plan

Do not schedule autonomous code-writing or image generation until the supervised loop has produced several clean merges.

## Phases

1. Phase 1: manual issue/PR loop.
2. Phase 2: manual read-only audit workflow.
3. Phase 3: scheduled read-only audit every 6 hours.
4. Phase 4: limited Codex PR creation.
5. Phase 5: reference-gated draft image generation.
6. Phase 6: human-approved 4K final generation.
